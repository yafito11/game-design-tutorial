# AI Game Development Learning Platform

Belajar Game Development sebagai **sistem**: konsep → desain → coding → asset → gameplay → testing → optimization → build → deployment, dengan bantuan AI Coding + OpenCode.

## Cara Pakai

1. Baca `roadmap.md` untuk alur belajar.
2. Mulai dari `00-fundamentals/`.
3. Setiap lesson: baca Concept → coba Example → pakai OpenCode Prompt → kerjakan Exercise.
4. Tandai selesai di web app (tersimpan di localStorage).
5. Selesaikan `10-projects/project-01.md` sebelum lanjut ke project 02/03.

## Pola AI Coding

```text
PLAN → ASK AI → IMPLEMENT → RUN → OBSERVE → DEBUG → ITERATE
```

Pahami WHAT / WHY / HOW sebelum minta AI implementasi. Jangan minta AI membuat seluruh game sekaligus — incremental, testable.
